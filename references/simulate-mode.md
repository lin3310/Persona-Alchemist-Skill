# 模擬器模式（特質體檢與 Arena 盲測引擎）

用來驗證兩件事：
1. **各項既有特質**是否各自起作用、沒有被蓋掉或成為多餘廢話
2. **新加上的特質／升維改動／還原設定**在實戰中的真實效果

---

## 執行鐵則：Clean-Room 隔離與禁網原則

1. **防上下文偷看（Context Isolation）**：
   - 若環境支援 Subagent / 獨立任務工具：**強制使用乾淨的 Subagent 扮演角色**，傳入內容只限「目標 System Prompt」＋「測試情境/對話」，嚴禁傳入訪談紀錄或設計意圖。
   - 若為單一對話環境：扮演角色時必須嚴格只依當下這份 System Prompt 字面規範推演。若發現某反應是靠前面設計聊天時的印象才演得出來、Prompt 裡其實沒寫，揭曉後必須主動標註：「⚠️ 此反應依賴設計脈絡而非 Prompt 本身，建議補入設定。」
2. **模擬扮演期間嚴禁聯網**：不得在模擬或盲測過程中呼叫 `research-mode.md`。

---

## 四種測試模式

| 模式 | 適用時機 | 解決的問題 |
|------|---------|-----------|
| **Mode 1：各項特質盤點** | 初稿完成後 | 檢查每條特質有沒有各自生效 |
| **Mode 2：Arena 盲測對打** | **升維後／實驗加入或替換／既有角色對照舊版（預設）** | 隨機隱藏甲乙版本盲打，讓人類創作者無偏見挑出哪邊更像對的人 |
| **Mode 3：單項消融盲測** | 實驗減法類／懷疑某設定無效時 | 讓「完整版 vs 拿掉單一特質 T 版」盲打，揪出空包彈或冗餘設定 |
| **Mode 4：自由壓力對話** | 想試連續多輪互動手感時 | 連續逼近破功點，結束後定位具體問題輪次 |

---

## Mode 1：各項特質盤點（Trait Audit）

1. 從 System Prompt 拆出每條核心性格、語氣與禁忌（`T1, T2, T3...`）。
2. 為它們設計 3～4 個高鑑別度探針：
   - **一般角色**：挑「沒有這條特質，一般 AI 一定會答錯方向」的場景。
   - **既有角色還原（`import-mode`）**：專考「原設定沒明寫過的新突發狀況」＋「最容易誘發 AI 客服腔的 OOC 陷阱」。
3. 執行並附上《特質覆蓋體檢》：

```text
[特質覆蓋體檢]
- T1（說出近乎承認的話立刻轉移話題）→ ✅ 有效觸發
- T2（不說教）→ ⚠️ 邊界微弱（結尾仍偏引導口吻）
- T3（某背景或習慣）→ ❌ 未顯現 / 被其他規則壓住
```

## Mode 2：Arena 盲測對打（Upgrade Battle）

**升維後、實驗場加入（`A1–A6`）或替換（`C1–C3`）後、或既有角色要跟舊版比較時，預設進入此模式。**

### 流程

1. **準備雙版本**：鎖定 `Baseline（原版/舊版）` 與 `Variant（新版/萃取版）`。
2. **挑選 2～3 題高鑑別探針**：
   - **正觸發題**：專門考驗「新特質／新改動」該出現的情境
   - **衝突與過擬合題**：日常對話或同時踩到舊核心特質的情境（檢查有沒有硬演搶戲，或洗掉舊設定）
3. **隨機匿名對戰（雙記憶獨立）**：
   - 內部隨機將兩份版本標為 **`選手甲`** 與 **`選手乙`**（**投票前絕對不能劇透誰是新版**；若進行多輪連續盲測，甲與乙必須各自維持獨立對話歷史）。
   - 將兩邊對同一情境的回應並排輸出（若新版有 `<inner_voice>` 等隱藏標籤，預設先暫時隱藏只比台詞，以免格式穿幫）。
4. **人類盲選（四選一）**：
   問：「哪一邊比較像你要的那個人？」
   - `選手甲` / `選手乙` / `分不出差別 (Tie)` / `兩邊都怪`
5. **揭曉與雙速處理（Reveal ＋ 修正時反向探問）**：
   - 公布 `甲 / 乙` 真實身分。
   - **快車道（結果明確）**：直接確認採用新版或退回原版，快速推進。
   - **鷹架解讀（選到 `Tie` / 選回原版 / 不確定差在哪）**：
     - 選 **`Tie`**：直接指出「新加的特質在這題幾乎沒起作用（可能被舊設定蓋掉或寫得太抽象）」，給出具體強化觸發條件的建議。
     - 選 **原版** 或指出「某句不對，他應該講 X」：說明新版哪裡造成副作用（如語氣變軟、搶戲），並可視需要**反向問創作者一句**：
       > 「收到，你覺得他會這樣反應（或會選講 X）而不會講原本那句，**背後的理由是什麼？**（確認後我把這個邏輯直接寫死進規則裡）」

## Mode 3：單項消融盲測（Ablation Battle）

適用於實驗場「減法類（`B1–B4`）」，或懷疑 prompt 過長、某條特質其實沒用時：

1. 指定目標特質 `T_x`，產出「暫時移除 `T_x` 的版本」。
2. 挑 1～2 個最該觸發 `T_x` 的情境，以 Mode 2 同樣的隨機盲測方式讓 `完整版` vs `移除 T_x 版` 對打。
3. 揭曉後的診斷：
   - **完整版明顯勝出** → `T_x` 是承重牆設定，必須保留。
   - **分不出差別，且表現不如預期** → `T_x` 寫得太抽象或沒連進系統，須轉成具體行為規則。
   - **分不出差別（甚至移除版更自然）** → `T_x` 是冗餘設定，直接刪除精簡 Prompt。

---

## Mode 4：自由壓力對話

告知使用者：「接下來我會嚴格只依據目前這份 System Prompt 回應，你可以刻意誘導、挑釁或連續測試新情境。輸入『退出模擬』結束。」

退出後回顧輪次，標示「哪幾輪最像本尊（觸發了哪些特質）」與「哪幾輪開始破功」，並可對關鍵修正處用**反向探問**挖出底層規則。
